# Operation: I'm Sorry

A Call-of-Duty-style first-person shooter where you are the boyfriend, and the
only objective is getting **Lara** to forgive you.

Your enemies are your own flaws: **Excuses**, **Left on Read** ghosts,
**Stubbornness**, and the final boss, **Pride**. Lara is on the radio the whole
time. She starts out cold and warms up as you prove yourself. Beat all four
missions, walk up to her, and ask the question.

Pure vanilla HTML/CSS/JS: a hand-written raycasting engine on a `<canvas>`.
No libraries, no image or audio files (every texture, sprite and sound is
generated by code).

## Play

Open `index.html` in a browser (or serve the folder: `python3 -m http.server`).

| Key | Action |
| --- | --- |
| `W A S D` | move |
| Mouse | aim (click to capture the mouse) |
| Left click | fire |
| `Shift` | sprint |
| `R` | reload |
| `1` / `2` / `Q` / wheel | switch weapon |
| `Esc` / `P` | pause |
| `M` | mute |
| `F` | fullscreen |

If the mouse can't be captured (some embedded viewers), the arrow keys turn and
look, and holding the right mouse button and dragging also looks around.
On phones/tablets, use landscape: left thumb moves, right thumb looks, plus
on-screen FIRE / RLD / SWAP buttons.

Three difficulty levels: Recruit, Regular, Veteran. Health regenerates, and
chocolates restore it fully.

## Make it yours

Everything personal is in **`config.js`**: your name, the letter Lara reads at
the end, the question, her reply, and how she looks (hair, skin, dress colour).
You can also set your name from the link: `index.html?from=Ahmed`.

Her radio lines and the mission text are in `levels.js`. The maps are plain
ASCII in `maps.js` (legend at the top of the file), so you can add rooms,
enemies or inside jokes.

## Send it to her

```bash
node build.js        # -> dist/sorry-lara.html
```

`dist/sorry-lara.html` is the whole game in one file. Send it, put it on any
web host, or enable GitHub Pages. It works fully offline.

## Files

| File | What it does |
| --- | --- |
| `engine.js` | raycaster: textured walls, floor/ceiling casting, sprites, fog |
| `art.js` | procedural textures and every sprite |
| `viewmodel.js` | first-person weapons and Lara's radio portraits |
| `audio.js` | synthesised sound effects and music (Web Audio) |
| `game.js` | enemies, boss, weapons, HUD, story flow, input |
| `levels.js` / `maps.js` | missions, dialogue, and the ASCII maps |
